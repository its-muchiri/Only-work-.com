# Contributing

Thanks for helping improve Onlywork.

1. Open an issue first for larger changes (layout, new sections, deployment).
2. Keep pull requests focused: one logical change per PR.
3. Match existing HTML/CSS style (semantic HTML, CSS variables, no frameworks
   unless discussed).
4. Verify the site locally (open `index.html` or run a static file server) and
   that GitHub Pages still deploys if you touch workflows.
